9. DATASET ANOMALY INVESTIGATION
================================

During validation, one image was found to contain only four
non-empty captions instead of five.

Problematic image:

```
2199200615.jpg
```

The four valid captions are:

```
1. A dog running on green grass with its mouth open and
   tongue hanging out.

2. a white dog is running with its mouth open across the
   grass.

3. A white, black, and brown dog runs in a field.

4. A dog runs across the grassy field.
```

The raw annotation file contains a fifth row for the same image,
but the caption field is empty.

Raw annotation structure:

```
2199200615.jpg, A dog running on green grass...
2199200615.jpg, a white dog is running...
2199200615.jpg," A white, black, and brown dog runs..."
2199200615.jpg, A dog runs across the grassy field.
2199200615.jpg,
```

The problematic row is:

```
Row 20001
```

============================================================
11. HANDLING OF THE EMPTY CAPTION
=================================

The original dataset was NOT modified.

The empty caption was NOT replaced with an artificial caption.

The image was NOT deleted.

The caption was NOT duplicated.

Instead, the preprocessing pipeline was modified so that empty
captions are explicitly detected and recorded as dataset-quality
anomalies.

The following information is recorded:

```
Empty caption count
Empty caption row number
Corresponding image ID
Empty caption value
```

For this dataset:

```
Empty caption count: 1

Row: 20001
Image: 2199200615.jpg
```

This allows the dataset to remain faithful to the original
annotations while preventing empty captions from being used as
valid textual information during later processing.
